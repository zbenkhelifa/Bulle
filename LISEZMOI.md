# Mission Bulle

Jeu de plateforme illustré pour le thème Réseaux sociaux de SNT (identité numérique, confidentialité et publicité ciblée, graphes, cyberharcèlement).

- `index.html` : la page (menus, HUD, écran de jeu)
- `style.css` : le style illustré de la page
- `game.js` : tout le jeu en JavaScript pur (canvas 2D, aucune dépendance)

Pour jouer : ouvrir `index.html` dans un navigateur, ou publier le dossier sur GitHub Pages.
Pour modifier un niveau : chercher `const LEVELS` dans `game.js` (chaque niveau est construit avec `ground`, `plat`, `spikes`, `ent`).
